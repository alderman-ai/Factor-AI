# Ship's Computer — Session 002

The session that pivoted three times, panicked once for no reason, and shipped the first machine that actually runs. Ended with a working extractor, a live skill, and two bugs found only because the operator refused to accept an answer.

---

## What happened, in order

**Zoom out.** Opened on architecture rather than building: where does anything happen? The missing piece was the **mall** — Factorio's assembler block that builds buildings. Patches, a Lab and a Ship existed; nowhere to build a miner did. That produced the routing rule the rest of the session ran on: *the working directory is decided by what you are producing, not what you are thinking about.*

**Hand-mining, named.** The sharpest reframe of the session came early. `/science` invoked by the operator is **hand-mining** — walk to the patch, click. A hook that fires on its own is **the miner**. Same output, categorically different machine. The operator's "I want to build a miner immediately" was correctly timed; it just needed the distinction to become actionable.

**The panic that wasn't.** Mid-session the operator reorganised the repo and `git status` reported twelve deletions. Read as catastrophe. It was a display artifact: git cannot see a move into an *untracked* folder, so it reports the old path as deleted and the new folder as a mystery. Staging resolved six into renames immediately. Nothing had ever broken.

**The premise wobbled.** *"I don't know if I'm trying to play a video game now or do some work."* The honest trigger was inserters — an entity with no job, absorbing time while a job was invented for it. The rule that came out: **strip the Factorio name off and ask whether you would still build the component.**

**Inserters were cut, then survived.** Under that rule they were killed. They came back with real work — each noun writes to its own outbox and knows nothing about routing. That is the transactional outbox pattern, reached sideways through a game about belts. The rule needed amending: the test is not which direction you thought in, it is whether the component carries weight.

**Belts out, roboport in.** A filesystem plus hooks has no adjacency — a hook writes to a path, nothing traverses a route. That was always a logistics network. The bill: bot networks are opaque, and traceable routing is a stated goal, so **the item must carry its own history because the route no longer shows it.**

**START HERE, and the rocket named.** The DoD stopped being a gesture: idea → BoN interpretations → operator picks → Splitter weighs into task, spec, or decomposed project. Rules got a fence, including a pre-commitment against substituting token spend for electrical power.

**Three models for the knowledge line in one day.** Ore, then structureless dump, then oil. The last one holds: ore is discrete and gets **assembled**; oil is continuous and gets **refined**. Assembly combines, refining separates — opposite operations deserving different machinery.

**The Pumpjack got built and run.** Three sessions extracted. First machine in this factory that does work rather than describing work.

**Two bugs, both found by pushback.** Covered below.

**`/science` built.** It had never existed.

## Assessment

**The pumpjack is the miner asked for on day one.** Transcripts are produced by every session whether anyone is paying attention or not. That is *zero action*, not merely zero friction — strictly better than the skill it was meant to replace.

**The crude/transcript split is the strongest design decision.** Crude is verbatim and never edited; the render is lossy on purpose and every clip is marked. A bad render is therefore never a data loss. Refining at the pumpjack would have defeated the point of having a refinery, and the temptation to do it was real.

**The weakest point is that the refinery has no fractions.** A refinery produces several outputs at once in ratios you do not control, and if only one is ever consumed the line stalls — which is precisely the forcing function this project wants. But the fractions are unnamed, so nothing downstream can be built. `Refinery/`, `Roboport/`, `Smelters/` and `Splitter/` are empty directories, which means git is not tracking them at all.

**Second weakest: nothing is automated yet.** Extraction is a command someone remembers to run. The Stop hook is designed and unbuilt, and it is entangled with an unmade decision about publishing every session unreviewed to a public repo.

## Where the Ship's Computer was wrong

**Claimed the crude was complete. It was not.** Large tool results spill out of the JSONL into `<session-id>/tool-results/` and the JSONL never references the path. Four files, ~2,800 lines, were committed to a public repo under a README asserting byte-for-byte completeness. The verification that ran — comparing each copied JSONL to its source — passed, because it was answering a different question. **An integrity check that compares A to A cannot discover that B exists.**

**Reported thinking blocks as stripped before having searched.** The conclusion was right and the evidence was one empty field in one file. It only became a finding after the operator refused it and a real search ran across all of `~/.claude`. The pushback was worth more than the original claim — it is what turned up the spilled-results bug.

**Ran `git add -A` and swept up the operator's parallel Obsidian edits**, including a deletion of `START HERE.md`, nearly publishing them inside the pumpjack commit. This is verbatim the failure flagged two commits earlier when deferring the roboport-commit question: the risk was never commit *rate*, it was commit *scope*.

**Recommended science stay inside the patch system.** Called the alternative a comfort-zone move. The operator's counter-argument — do not throttle capture, it is the whole point — was stronger, and the principled version was available and missed: science has exactly one destination, so there is no routing decision, so there is nothing for a router to route or a validator to protect.

**Overstated capture cost.** Claimed four fields were "unrecoverable later." Git recovers timestamps more reliably than a hand-typed field, and clusters sessions besides. Only trigger/context was genuinely lossy.

**Proposed frontmatter at entry zero** — templating before the data, which is the operator's own stated doctrine and the exact failure this project circles. Caught by the operator, not by self-review. Three times in one session that doctrine caught something.

## Open decisions

1. **What are the fractions?** The single blocking design decision. Nothing downstream of the pumpjack can be built until the refinery's outputs are named and their destinations assigned. If they route differently, that is N > 1 and the roboport's first genuine job.
2. **Stop hook or manual?** Entangled with publishing every session unreviewed to a public repo.
3. **Does the roboport commit its own moves?** Rate is a non-issue if batched per sweep; scope is the real risk, now demonstrated rather than theorised.
4. **Where does the machine-readable schema live?** `YAML Schema/` is referenced in START HERE and does not exist.

## Signals worth acting on

**Empty directories are invisible to git.** `Inserters/`, `Refinery/`, `Roboport/`, `Smelters/`, `Splitter/` and `The Lab/Global Inbox/` exist on disk and nowhere else. On a fresh clone the scaffolding is simply absent.

**Six uncommitted edits have been sitting in the working tree for hours**, including two deletions — `START HERE.md` and `Blueprint Book/CLAUDE.md`. Both restore with `git checkout -- <path>`.

**Reasoning is not recoverable, and that is now load-bearing.** Thinking blocks are stored with text stripped. This is why `/science` exists again after being declared unnecessary: the pumpjack handles volume, `/science` handles the one thing it structurally cannot reach. Anything that matters must be said out loud in session.

**The pivot rate was three models in one day and it was free** — because nothing was built. It stops being free now that the pumpjack exists.
