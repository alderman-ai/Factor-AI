
Ore Patches is a root level folder that contains multiple Miner subfolders. Ore Patches/ is a location for all types of possible Ore in this system. The Ore Category is denoted by the naming of the Miner folder and its contents, as well as in the front header of the Ore Patch.md (e.g. Science Ore Patch.md)

In our Lexicon, Ore is a template file. An Ore Patch.md is the original template which is copied but not edited. Mined Ore is a template that has been copied and ready for the copy to be filled in. And Smelted files are filled in templates.
