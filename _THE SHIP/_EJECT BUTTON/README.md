# What is the Eject Button?

The process of closing out one Factor-AI Run, learning and adjusting from any
problems, and when ready launching a new one.

**Read this folder first in any session that opens between runs.** It is where
a session picks up what is in progress.

## The two rituals

They are split on purpose and each names the other.

- **`Biter Attack Ritual/Commit Ritual.md`** — governs what **git** does.
  Tags, ranges, the commit order. Nothing in it moves a file.
- **`Biter Attack Ritual/File Move Ritual.md`** — governs what moves **on
  disk**. Nothing in it creates a commit.

Where a step does both, it is split across the two documents.

## The per-run documents

Two files accrete here per run, and they are not the same thing:

| File | Written | By whom | With what |
|---|---|---|---|
| `RUN-NNN-Assistant-Report.md` | **Before** the scuttle | the run that is dying | only what that run could know |
| `RUN-NNN-Autopsy.md` | **After** the scuttle | a later session | hindsight the run did not have |

Merging them would rewrite history. The report is the toll — a reset is legal
only once it exists. The autopsy is the post-mortem.

`INDEX.md` lists what is currently here.
