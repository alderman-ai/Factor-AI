# Atlas of Worlds

Every `New World NNN.md` that has been retired, kept forever.

**A world's coordinates are never deleted.** They are the only surviving record
of what each run was asked to be, and the run numbering is derived from them.
The world dies; the request that made it does not.

Files arrive here by `Ignition Codes/chart_course.py`, moved and not copied — a
copy would leave the retired world on the Panel beside the new one, and the next
chart would archive both.

A name collision here means a run number is being reused. The script refuses.
That is a ledger fault and gets fixed in the ledger, never by renaming the file
that tripped it.

Accretes forever. No INDEX — one file per run, numbered, so the filename is the
routing.
