# Schema

- Run: sequential NNN, see README
- Difficulty: (Easy | Normal | Hard)
	- Easy: focus on world building and developing the methodology behind the game, include purposeful friction to test operator improvement categories infrequently
	- Normal: Balance between world building and learning
	- Hard: Prioritize learning, Purposefully surface gaps in operators knowledge and stage friction events to capture learnings
- Length: (Quick | Short | Normal | Long | Epic )
	- Quick: let's get straight to the point, test a very specific thing, learn a bit, then wrap up
- World Objective -- the world or system building goal to hopefully expand towards
- Learning Objective -- the blind spot to focus on testing this run (if empty, the assistant decides)
