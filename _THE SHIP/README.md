# The Ship

The durable half of Factor-AI. **Everything in here survives every reset.**

A run kills a world. It never touches the Ship. That asymmetry is the whole
design: the planet is disposable so that failure is cheap, and the Ship is
permanent so that failure accumulates into something.

**Nothing temporary spawns here.** Run-lifetime objects live at repo root. See
`Hitchhiker's Guide/Ontology/The Crate.md`.

`INDEX.md`, beside this file, routes to the six things inside.
