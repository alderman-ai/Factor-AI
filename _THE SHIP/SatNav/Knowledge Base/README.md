# Knowledge Base

The refined end of SatNav. Filed, retrievable, novel failure-solution pairs.

**This is the Key Long-term Output.** Everything else in this repo is scaffolding
for producing what goes in here.

An entry earns a place by being a *pair* — a failure that actually happened and
the thing that fixed it. A lesson with no failure attached is an opinion. A
failure with no fix is a log entry, and belongs in `Distress Beacon/`.

Currently empty. `INDEX.md` beside this file is the catalogue and accretes as
entries are filed.
