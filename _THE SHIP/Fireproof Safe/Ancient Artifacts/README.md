# Ancient Artifacts

**Things worth preserving as inspiration for future runs.**

Not a graveyard and not a canon store — a shelf of things that were interesting
enough to keep looking at. Something lands here because a future run might want
to steal from it, not because it is still in service.

Two things in here need their status stated plainly, because the name misleads:

| File | Status |
|---|---|
| `Lexicon.md` | **Live canon.** The glossary the whole repo routes to. It sits here for historical reasons, not because it is retired. |
| `Science Ore Patch.md` | Live reference. The worked example the public README points at. |
| `pumpjack.py` | **Not live.** An older version. The one that actually runs is `Instrument Panel/Ignition Codes/pumpjack.py`. Kept here for the parts of the design that got dropped — a `crude/` copy beside the render, so a bad render is never a data loss. |

If `Lexicon.md` ever moves, the root `README.md` and the root `CLAUDE.md`
reading list both point at it by path.
