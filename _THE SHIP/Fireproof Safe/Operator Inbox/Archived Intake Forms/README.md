# Archived Intake Forms

Where a form goes once it has been dealt with — **retired regardless of
outcome**, not only when answered.

Approved, deferred, abandoned, or answered wrong: it archives. The point is the
record, not the resolution. A batch where half the slots were deferred is
evidence about how the batch protocol behaves under load.

Accretes forever. Nothing here is edited after it lands.
