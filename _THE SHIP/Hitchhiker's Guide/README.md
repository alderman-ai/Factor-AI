# Hitchhiker's Guide

**The rules.** How the components of Factor-AI are defined and how they
interact.

This is the folder the assistant is bound by. `Fireproof Safe/` is the
operator's shelf and governs nothing; this governs everything.

The root `CLAUDE.md` reading list points into here by path, with a trigger
condition per page — the Guide is fetched on demand, not auto-loaded.

`INDEX.md`, beside this file, routes to what is inside.
