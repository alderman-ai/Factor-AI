# Ontology

**The long version of the rules.** What each component of Factor-AI is, and
what happens where two of them meet.

Read before adding a component, or before changing how two existing ones
interact. A page here is binding — if a rule is written down in this folder,
routing around it is the failure the fences exist to catch.

## Inside

| File | What it defines |
|---|---|
| `The Crate.md` | The only surface the Ship and the Guy trade across, and the rule that nothing disposable spawns inside `_THE SHIP/`. |
| `Intake Primitives.md` | The action tiers — Research, Action, Planning, State, Variable — and the resource each one costs. Its Action verbs are the **off-ship** set; the on-ship set lives in `Human Actions/`. Two scopes, not a contradiction. |

## Not this folder

- Intent and direction → `Instruction Manual/`
- Machine-validated form contracts → `Schema/`
- Ideas not yet ruled on → `Fireproof Safe/Game Improvement/`
