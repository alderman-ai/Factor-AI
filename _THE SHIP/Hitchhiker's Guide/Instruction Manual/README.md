# Instruction Manual

Canon **about** the project — what it is for, where it is going, why it is
shaped this way. Not the machinery.

That is the line between this folder and its two neighbours:

| Folder | Holds | Answers |
|---|---|---|
| `Instruction Manual/` | Intent | *Why does this project exist, and what would winning look like?* |
| `Ontology/` | Rules | *What is a crate, and what happens when it is full?* |
| `Schema/` | Contracts | *What fields must a world form have for the script to accept it?* |

An idea that has not been ruled on yet is neither of the three — it belongs in
`Fireproof Safe/Game Improvement/` until it becomes a rule.

## Inside

- **`Purpose of Factor-AI/`** — the five background pages lifted out of root
  `CLAUDE.md` so they stop being auto-loaded into every session. Root
  `CLAUDE.md` now carries a reading list that points here with a trigger
  condition per page.
