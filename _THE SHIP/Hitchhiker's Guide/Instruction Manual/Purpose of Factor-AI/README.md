# Purpose of Factor-AI

The **why** of this project, lifted out of the root `CLAUDE.md` so it stops
being auto-loaded into every session.

These pages do not change what the assistant does on a given turn. They change
what "correct" means over a run. Read one when the decision in front of you is
about direction, scope, or whether the game is still doing its job — not when
you are executing a task.

Root `CLAUDE.md` carries the routing table that points here, with the trigger
condition for each page. This folder holds the text itself.

Nothing here is instruction. It is all context. If a page ever starts telling
the assistant what to do on a turn, that paragraph belongs back in `CLAUDE.md`.
