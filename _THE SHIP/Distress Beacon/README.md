# Distress Beacon

Session notes, from both sides, kept in separate folders on purpose.

- **`Captains Log Entries/`** — the operator's. Durable notes written by Alex
  during the build.
- **`Ship's Computer Entries/`** — the assistant's. What a session saw, decided,
  and got wrong, written at the end of it.

Two folders rather than one because the value is in the disagreement. A single
merged log would let one side's account of a session quietly become the record.

Entries accrete and are never edited after the fact. Neither folder gets an
INDEX — they are date-ordered and homogeneous, so the filename is the routing.
