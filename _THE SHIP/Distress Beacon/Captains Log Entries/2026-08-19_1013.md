# (quick) Info System


## Components

Core directories that Claude will use as a working directory and will perform actions

- The Guy - right now can move things from dir-a/ to dir-b/ using Adrenaline for each move
- Power station - generates power and manages its movement
- Mine - oversees generation of ore in 1 or more ore patches
- The Ship too, but not in this demo

## Actions

A skill. In this demo it's literally git move artifact x to directory y

## Action Resources

Actions aren't free. Each action costs a resource.  A resource if an intake template that allows for ZERO PROSE and must comply with system rules to be executed (fun!).

No completed resource template? Too bad. No action

## Inert resources

Not templates. But still tracked for routing purposes. POWER, ORE
### Resource generation

A resource is an artifact that is copied on a loop by the Component that manages it.

The Guy generates Adrenaline artifact into his own directory (HOT!) 1x a minute. Moving something costs 2 Adrenaline (not fixed numbers, just for demo)

Mines generate ORE

Power station generates power. Power, at this point, is just a fixed item. The complexity in the future will be that there's a fixed number, and that you need X power in your generator to do automated tasks. And the power pole is in charge of moving the power around the system and prioritizing which automations happen (Fun! ... ?)
