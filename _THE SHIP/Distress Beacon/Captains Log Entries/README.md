# Captain's Log Entries

The operator's session notes. Written by Alex, in his own words, during the
build.

Filename is the date, optionally with a time when there is more than one that
day: `YYYY-MM-DD.md`, `YYYY-MM-DD-HHMM.md`.

Accretes forever. Never edited after the fact — a log that gets tidied up is
not evidence of anything.
