# Ship's Computer Entries

The assistant's session notes. What a session saw, what it decided, and what it
got wrong.

Filename is a local timestamp: `YYYY-MM-DD_HHMM.md`.

Accretes forever, and no INDEX — the folder is homogeneous and date-ordered, so
the filename is the routing. This is the example the operator gave when setting
the README/INDEX rule: a folder that accretes does not automatically need a
catalogue, only one whose contents you would otherwise have to open to tell
apart.

Not the same thing as a run report. A `RUN-NNN-Assistant-Report.md` in
`_EJECT BUTTON/` is the toll paid at a run's death, filed once per run. These
are per session.
